# first-principles

用**第一性原理**解决问题的 Claude / WorkBuddy skill。把问题拆到不可再分的基本事实，再从事实向上推导结论，而不是靠类比或默认假设。结论先行，再给推导与边界条件。

## 适用场景
- 拿不定主意的决定（换工作 / 买房 / 要不要做某个功能 / 团队流程怎么改…）
- 没想透的概念（"好像懂但说不清为什么"）
- 想挑战"大家都这么做 / 降本就该裁人"这类常识

## 安装

**方式一（源码）**——把本仓库 clone 到你的 skills 目录：

```bash
git clone git@github.com:richa-yuan/first-principles-skill.git ~/.workbuddy/skills/first-principles
```

**方式二（.skill 包）**——下载仓库根目录的 `first-principles.skill`，用客户端"安装 skill"导入即可。

## 怎么用
直接问，或显式说"用 first-principles 帮我拆…"。容易触发的话题示例：
- "从本质上 / 底层逻辑上看，这事到底怎么破？"
- "为什么大家都这么做？我想拆开看看。"
- "帮我真正理解 X（别给我教科书定义）。"
- 任何拿不定主意、想刨到根上的问题

即使你没提"第一性原理"四个字，只要是在挖底层而非接受表面直觉，它也会自动接手。
（不会触发：定义类问题、书单/课程推荐、翻译/写码/总结/画图等无关任务。）

## 输出结构
一句话结论 → 我们真正在解决什么 → 被借来的假设（先拆掉）→ 不可再分的基本事实 → 从基本面向上推导 → 什么情况下结论会变
